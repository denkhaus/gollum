# Gap Summary

**Critical Gap:** Built-in prompts are NOT protected from deletion

Root Cause:
1. `SaveNewVersion()` in memory_store.go:87 and file_store.go:108 hardcodes `IsBuiltin: false`
2. Bootstrap code in bootstrap.go:72 calls `store.SaveNewVersion()` which cannot set IsBuiltin=true
3. DeletePrompt checks IsBuiltin correctly (store.go:80), but it's always false

Design Decision (from analysis):
- Add a new `SaveBuiltinVersion()` method to PromptStore interface
- This is cleaner than modifying SaveNewVersion signature
- Separates concerns: user prompts vs built-in prompts
- Maintains backward compatibility - existing SaveNewVersion calls unchanged
- Both MemoryStore and FileStore implement the new method

Files to modify:
- pkg/prompt/store/store.go - Add SaveBuiltinVersion to interface
- pkg/prompt/store/memory_store.go - Implement SaveBuiltinVersion
- pkg/prompt/store/file_store.go - Implement SaveBuiltinVersion
- pkg/prompt/manager/bootstrap.go - Call SaveBuiltinVersion instead of SaveNewVersion
- Tests for both store implementations and bootstrap behavior
</context>
