  <name>Task 1: Implement template rendering with text/template</name>
  <files>pkg/prompt/manager_render.go</files>
  <action>
    Create new file pkg/prompt/manager_render.go with template rendering:

    Implement RenderPrompt method:
    ```go
    func (p *promptManager) RenderPrompt(ctx context.Context, prompt *Prompt, renderCtx *RenderContext) (string, error)
    ```

    Rendering logic:
    - Use text/template.New(prompt.ID).Parse(prompt.Content)
    - Build template data map from renderCtx:
      * Top-level: renderCtx.Values
      * SubAgent: if renderCtx.SubAgent != nil, add fields
      * Agent: if renderCtx.Agent != nil, add fields
    - Execute template with data map
    - Return rendered string or wrapped error

    Template data structure:
    ```go
    data := make(map[string]interface{})
    if renderCtx.Values != nil {
        for k, v := range renderCtx.Values {
            data[k] = v
        }
    }
    if renderCtx.SubAgent != nil {
        data["Role"] = renderCtx.SubAgent.Role
        data["Description"] = renderCtx.SubAgent.Description
        data["SpawnAgentTool"] = renderCtx.SubAgent.SpawnAgentTool
        // ... other SubAgentContext fields
    }
    if renderCtx.Agent != nil {
        data["AgentID"] = renderCtx.Agent.AgentID
        data["Task"] = renderCtx.Agent.Task
    }
    ```

    Implement GetPromptWithContext:
    ```go
    func (p *promptManager) GetPromptWithContext(ctx context.Context, id string, renderCtx *RenderContext) (string, error)
    ```
    - Call GetPromptByID(ctx, id)
    - If nil, return "", store.ErrPromptNotFound
    - Call RenderPrompt(ctx, prompt, renderCtx)
    - Return rendered string

    Error handling:
    - Wrap template.Execute errors with context about which prompt failed
    - Return clear error messages for missing template variables

    Dependencies:
    - Import "text/template"
    - Import "strings" for error wrapping
    - Import "fmt" for error formatting
  </action>

    go build ./pkg/prompt/...
  </verify>

  </done>
