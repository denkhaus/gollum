  <name>Task 2: Create integration helper for optimizer + store</name>
  <files>pkg/prompt/optimizer/integration.go</files>
  <action>
Create pkg/prompt/optimizer/integration.go with:

1. Package declaration: package optimizer
2. Imports: context, fmt, github.com/Masterminds/semver/v3, github.com/denkhaus/gollum/pkg/prompt, github.com/denkhaus/gollum/pkg/prompt/store
3. OptimizeAndSave function:
   - Signature: func OptimizeAndSave(ctx context.Context, optimizer PromptOptimizer, store store.PromptStore, promptID string, input *OptimizerInput) (*prompt.Prompt, error)
   - Flow:
     a. Load current prompt from store using store.Load(ctx, promptID)
     b. Call optimizer.Optimize(ctx, input) with current prompt content
     c. If result.WarrantsAdjustment is false, return original prompt with nil error
     d. Parse current version from promptID (extract semver if present, otherwise use 1.0.0)
     e. Increment version (patch increment for prompt changes)
     f. Create new versioned ID: "{baseID}@{newVersion}"
     g. Call store.SaveNewVersion(ctx, baseID, result.NewPrompt, name from original prompt)
     h. Return the saved prompt
4. Helper function:
   - extractBaseID(id string) string - strips version suffix (e.g., "supervisor@1.0.0" -> "supervisor")
   - parseVersion(id string) (*semver.Version, error) - extracts version from ID
5. Error handling for:
   - Prompt not found in store
   - Invalid version format
   - Optimizer errors
   - Store save errors
  </action>
  <verify>
go build ./pkg/prompt/optimizer/...
  </verify>
  <done>
Integration helper created that orchestrates optimization and saves results to store with proper version incrementing.
  </done>
