  <behavior>
    **Gradient Strategy:**
    1. Creates Gollem agent with think/critique/recommend tools
    2. Runs reflection loop (min 2, max 5 steps by default)
    3. Think tool: records reasoning about trajectory analysis
    4. Critique tool: challenges hypotheses
    5. Recommend tool: decides if adjustment warranted
    6. If warrants_adjustment=true, runs second phase to apply recommendations
    7. Returns new prompt with incremented SemVer and change description

    **Meta-Prompt Strategy:**
    1. Combines reflection and update in single LLM call
    2. Uses DEFAULT_METAPROMPT template
    3. Runs 1-5 reflection steps (default 2)
    4. Returns new prompt or original if no adjustment needed

    **Prompt Memory Strategy:**
    1. Single LLM call with DEFAULT_PROMPT_MEMORY template
    2. Includes trajectory, feedback, and instructions
    3. Returns new prompt or signals no update needed

    **Common Behavior:**
    - All strategies accept OptimizerInput with trajectories and current prompt
    - All return OptimizerResult with new prompt and change description
    - All use Gollem LLM client via dependency injection
    - All handle tool calls via Gollem's tool system
    - All respect min/max reflection steps configuration
  </behavior>
